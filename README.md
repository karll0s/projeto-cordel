# Cordel Moderno

Uma página web desenvolvida para apresentar o poema **Cordel Moderno**, de Milton Duarte, utilizando recursos de HTML5 e CSS3.

O projeto explora a criação de uma página com diferentes seções, efeitos visuais e imagens de fundo, buscando valorizar a leitura do poema.

## Tecnologias

- HTML5
- CSS3
- Google Fonts

## Recursos utilizados

- Layout dividido em seções.
- Imagens de fundo com efeito de paralaxe.
- Tipografia personalizada.
- Design responsivo baseado em unidades relativas.
- Efeitos de contraste e sobreposição de texto.
